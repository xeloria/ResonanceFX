# Security

ResonanceFX runs inside Android's audio server with root-installed files, so memory-safety bugs
in the engine (for example malformed parameters or impulse responses) matter.

Please report vulnerabilities privately through GitHub's
[security advisories](https://github.com/xeloria/ResonanceFX/security/advisories/new) instead of
a public issue. Include the affected version, the device and steps or a file that reproduces it.
